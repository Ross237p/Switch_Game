# 🎮 Super Easy Setup Guide (For Complete Beginners)

Welcome! This guide will get you playing Switch in just a few minutes - **no coding knowledge needed!**

## Step 1: Download the Game

1. Go to your GitHub repository page in a web browser
2. Look for the green **"Code"** button near the top
3. Click it and select **"Download ZIP"**
4. Save the ZIP file to your **Desktop** (or anywhere you can find easily)
5. **Right-click** the ZIP file and choose **"Extract All"** or **"Unzip"**
6. You now have a folder called `Switch_Game`!

## Step 2: Install Python (One-time only)

**Don't have Python?** No worries!

### Windows:
1. Go to https://www.python.org/downloads/
2. Click the big **"Download Python"** button
3. Run the downloaded file
4. ✅ **IMPORTANT**: Check the box "Add Python to PATH"
5. Click **"Install Now"**
6. Wait for it to finish, then close

### Mac:
1. Go to https://www.python.org/downloads/
2. Click **"Download Python"**
3. Open the downloaded file
4. Follow the installation steps
5. Done!

**Already have Python?** Skip to Step 3!

## Step 3: Play the Game! 🎉

### Windows Users:
1. Open the `Switch_Game` folder
2. Find the file called **`PLAY_GAME.bat`**
3. **Double-click it**
4. The game starts! 🎮

### Mac/Linux Users:
1. Open the `Switch_Game` folder
2. Find the file called **`PLAY_GAME.sh`**
3. **Double-click it** (or right-click → Open)
4. The game starts! 🎮

## That's It!

From now on, whenever you want to play:
- Just **double-click** `PLAY_GAME.bat` (Windows) or `PLAY_GAME.sh` (Mac/Linux)

---

## 🎯 How to Play the Game

Once the game starts:

1. **Enter your name** (or just press Enter)
2. You'll see:
   - **Top card** on the table
   - **Your hand** (numbered 1, 2, 3, etc.)
   - **Opponents' card counts**

3. **On your turn:**
   - Type a **number** (1, 2, 3...) to play that card
   - Type **`d`** to draw a card (if you can't play)
   - Type **`h`** to see the rules
   - Type **`q`** to quit

4. **Goal:** Get rid of all your cards before your opponents!

### Quick Rules:
- Match the **suit** (♠♥♦♣) or **number/letter** of the top card
- **Special cards:**
  - **A** = Wild (choose any suit)
  - **2** = Next player draws 2 cards
  - **7** = Play multiple cards of same suit
  - **8** = Skip next player
  - **J** = Reverse direction
  - **K♠/K♣** = Next player draws 5 cards
  - **K♥/K♦** = Block the Black King

## ❓ Troubleshooting

### "Python is not recognized" error?
- You need to install Python (see Step 2)
- OR you forgot to check "Add Python to PATH" during installation
- Solution: Uninstall Python and reinstall it, making sure to check that box!

### File won't open on Mac?
- Right-click `PLAY_GAME.sh`
- Hold the **Option** key and click **"Open"**
- Click **"Open"** again to confirm

### Still stuck?
- Make sure you **extracted/unzipped** the folder first
- Make sure you're double-clicking inside the extracted folder, not the ZIP file
